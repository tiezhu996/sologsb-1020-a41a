# 档案元数据核对台

`sologsb-1020` 是一个用于口述史与手稿档案元数据比对的本地优先前端工作台，使用 Qwik、TypeScript 和 Qwik UI 构建。

## 功能

- 导入 A / B 两组记录，支持 JSON 数组、制表符和竖线分隔文本。
- 按标题、日期、人物、地点和编号加权匹配，显示综合分数与判断依据。
- 键盘密集复核：J/K 移动、Enter 合并、C/R 确认或忽略，支持批量操作。
- 合并时逐字段并排展示 A / B 来源，每个冲突字段可单独保留或拼接。
- 保存原始记录、字段来源选择、合并结果和忽略动作，形成完整审计轨迹。
- 支持撤销重做、离线 localStorage 保存和 JSON 核对包导出。
- 大量记录采用分批窗口渲染，匹配计算限制每条记录的候选数，避免一次挂载全部行。

## 封存归档

核对完成后可发布到封存服务（同页模拟，独立 localStorage，可一键断网 / 重置）：

- **职责分离**：本机工作区保存核对结论、字段选择和撤销记录；封存服务保存对象摘要、发布批次和封存状态。
- **对象复用**：发布先按规范化内容摘要查找 / 登记对象，同一结论重复提交只复用对象，不重复建档。
- **批次预留**：再为对象预留发布批次（30 秒 TTL），归属以先预留者为准；封存写入失败后批次保留，恢复同一批次重试即可，幂等键保证不重复建档。
- **断网恢复**：断网时结论停在本机（queued）或失败前的阶段，重连后继续走同一批次。
- **撤回与补偿**：撤回已封存的合并会恢复原记录并生成补偿任务，列出受影响记录、引用对象和当前封存版本；确认后在同一对象上追加新版本，旧版本完整保留。
- **并发对账与接管**：两人同时发布时以批次预留定归属，可做发布对账；他人预留过期后可接管，交接过程写入封存服务流水。
- 顶部「封存归档」区提供发布队列、补偿任务、对象版本链、批次状态和完整服务流水，可用「模拟工位-乙抢预留」「下次封存失败」「断网」演练异常路径。

封存流程有一组无外部依赖的断言脚本：

```bash
npm run verify:publish
```

## 技术栈

- Qwik 1.20
- TypeScript 5.9
- Qwik UI Headless `@qwik-ui/headless`
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务使用 Vite 默认端口，不在源码中硬编码宿主端口。

## 生产构建

```bash
npm run build
npm run preview
```

静态产物输出到 `dist/`。

## Docker

```bash
docker build -t sologsb-1020 .
docker run --rm -p 10020:80 sologsb-1020
```

nginx 在容器内监听 `80`，宿主端口 `10020` 由根端口表或运行命令映射。

## 数据说明

记录和审计轨迹保存在当前浏览器。导入新记录后自动重新计算候选匹配，但不会自动确认或覆盖任何字段。
