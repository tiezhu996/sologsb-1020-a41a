# 档案元数据核对台

`sologsb-1020` 是一个用于口述史与手稿档案元数据比对的本地优先前端工作台，使用 Qwik、TypeScript 和 Qwik UI 构建。

## 功能

- 导入 A / B 两组记录，支持 JSON 数组、制表符和竖线分隔文本。
- 按标题、日期、人物、地点和编号加权匹配，显示综合分数与判断依据。
- 键盘密集复核：J/K 移动、Enter 合并、C/R 确认或忽略，支持批量操作。
- 合并时逐字段并排展示 A / B 来源，每个冲突字段可单独保留或拼接。
- 保存原始记录、字段来源选择、合并结果和忽略动作，形成完整审计轨迹。
- 支持撤销重做、离线 localStorage 保存和 JSON 核对包导出。
- 大量记录采用分批窗口渲染，匹配计算限制每条记录的候选数，避免一次挂载全部行。

## 核对完成后的封存归档

核对结论可发布到独立的「封存服务」（同一页面内模拟，独立 localStorage 命名空间，与本机工作区物理隔离）：

- **本机工作区**管核对结论、字段选择、合并撤回记录与发布作业；**封存服务**管对象摘要、发布批次、封存状态与版本链。
- **对象摘要复用**：发布内容先按规范化字段计算摘要，封存服务对同摘要对象直接复用（`reuseCount`），同引用同摘要不重复建版本。
- **先预留批次再封存**：预留批次带操作员归属与 TTL（可调 10–60 秒），以批次预留定归属；每个作业有幂等键，**发布失败后恢复同一批次，重试不会重复建档**。
- **断网与响应丢失**：故障注入支持「断网 / 预留响应丢失 / 封存响应丢失」；响应丢失时服务端可能已生效，用「发布对账」发现差异——本机超前可恢复同一批次，服务超前可一键补登对齐。
- **撤回合并与补偿**：撤回已封存的合并会恢复两条来源记录并生成补偿任务，列出受影响记录、引用对象和封存版本；确认后发布**新版本并保留旧版本**（版本链 `supersededBy`）。未封存的合并撤回无需补偿。
- **两人同时发布**：重叠引用在预留阶段冲突并返回归属批次信息；他人活跃预留不可封存，**过期预留可接管**，接管动作写入批次履历与服务事件流。
- 顶部可切换操作员（研究员甲 / 乙），封存服务面板可查看批次、版本链、服务履历，并可清空服务数据制造两侧不一致来演练对账。

## 技术栈

- Qwik 1.20
- TypeScript 5.9
- Qwik UI Headless `@qwik-ui/headless`
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务使用 Vite 默认端口，不在源码中硬编码宿主端口。

## 生产构建

```bash
npm run build
npm run preview
```

静态产物输出到 `dist/`。

## Docker

```bash
docker build -t sologsb-1020 .
docker run --rm -p 10020:80 sologsb-1020
```

nginx 在容器内监听 `80`，宿主端口 `10020` 由根端口表或运行命令映射。

## 数据说明

记录和审计轨迹保存在当前浏览器。导入新记录后自动重新计算候选匹配，但不会自动确认或覆盖任何字段。
